# Pulse (React + Firebase)

Social web app for **everyone** — shared data via Firebase. Web first, app later.

## Quick start
```bash
npm install
cp .env.example .env   # add Firebase web config
npm run dev
```

## Scripts
- `npm run dev` — local
- `npm run build` — production `dist/`
- `npm run preview` — preview build

## Docs
- `LAUNCH.md` — web launch steps (Hindi/English mix)
- `FIREBASE_SETUP.md` — Firebase console steps
- `netlify.toml` — Netlify SPA config

## Stack
React · Vite · Tailwind · React Router · Firebase · Lucide
